# xD-keyboard
This is a 60% layout extended keyboard made with Gateron KS-33 Low profile switches with Hotswap socket supported by onboard MCU, nrf52840.

## Firmware 

It is a dual functionality keyboard which supports wireless(Bluetooth) & wired connection without any switch. This keyboard is powered by ZMK firmware with a onboard battery with Ultra low power optimization.

## PCB Design

It is a PCB keyboard which has a 4 layer or 6 layer and was designed by both Kicad(Schematics) & Easyeda Pro(Routing). JLCPCB is used for PCB fabrication.
