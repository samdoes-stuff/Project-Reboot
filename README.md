# xD-keyboard
This a 60% layout extended keyboard made with Gateron KS-33 Low profile switches with Hotswap socket supported by onboard MCU, nrf52840.

## Firmware 

It is a dual functionality keyboard which supports wireless(Bluetooth) & wired connection without any switch. This keyboard is powered by ZMK firmware with a onboard battery with Ultra low power optimization.
Adafruit github repo for nrf52 has been used to make the firmware for Our on board MCU.

## PCB Design

It is a PCB keyboard which has a 4 layer or 6 layer and was designed by both Kicad(Schematics) & Easyeda Pro(Routing). JLCPCB is used for PCB fabrication.

## 3D

Keyboard Case and Plate were 3D designed by Fusion 360. And Later was Sliced in Bambu Studio into STL files. 

## BOM

Build BOM was generated based on the LCSC part list & prices. And Switch, Hotswap sockets and keycaps were priced after Aliexpress Listing.
